Privacy Policy

Last updated: 13 November 2026

Nirmal Library, Bidhuna (Auraiya, Uttar Pradesh) runs an admin panel at nirmallibrary.in to manage student admissions, fee records, seats and expenses. This policy explains what information the app handles and how it is used. The panel is for library staff only; it is not a public service.

Information we handle

  • Library records entered by the admin: student names, mobile numbers, seat numbers, fee and payment details, expenses, and optional uploaded photos or ID images.
  • Admin login details: the admin email address and password, handled by Firebase Authentication (Google).
  • Settings stored in your browser: theme, seat count, and the time of your last backup (browser local storage).

How the information is used

Records are used only to run the library: showing fee dues, sending WhatsApp reminders and receipts that the admin starts manually, and creating backups. We do not sell, rent or share this information with anyone for advertising or marketing.

Where it is stored

Library records are stored in Google Firebase (Cloud Firestore). Access is limited to logged-in admin accounts.

Google Drive backup

If the admin chooses Connect Google Drive, the app asks for the permission drive.file. With it the app can only create and access files that it created itself. It cannot see, read or change any other file in your Google Drive.

  • The app uses this permission only to create a folder called "Nirmal Library Backups" and upload backup (Excel) files into it, at the admin's request.
  • Backup files go directly from your browser to your own Google Drive. They do not pass through any server of ours.
  • The Google access token is kept in your browser's memory only for the current session and is not stored on any server.
  • You can disconnect at any time using the Disconnect button in the app, or at myaccount.google.com/permissions.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Records are kept as long as the library needs them. Deleted students stay in the recycle bin until removed. Backup files in Google Drive are under your control, and you can delete them from Drive at any time. To request deletion of a student's data, contact the library.

Security

Data is transmitted over HTTPS, access requires an admin login, and sessions end automatically after 30 minutes of inactivity. No system is perfectly secure, so admins should use a strong password and keep backups.

Children

Students may be minors. Their details are entered by library staff or parents for admission and fee purposes only and are not used for any other purpose.

Changes

We may update this policy; the date above shows the latest version.

Contact
